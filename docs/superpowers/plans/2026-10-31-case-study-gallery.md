# Case Study Gallery (図) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Projects carry ordered figures (uploaded images and admin-rendered Mermaid diagrams) that visitors open from the 掛軸 case study panel in a 絵巻 view and study in a full-screen 書院 viewer.

**Architecture:** A new `projects.media` jsonb column validated by one Zod `figureSchema`; public view models drop the Mermaid source and attach localized figure views to case study items. The panel gains a lazy 図 chunk (stage, filmstrip, `fig` deep link) and a second lazy chunk for the viewer (pure zoom/pan math in `src/lib/figures/zoom.ts`). The admin renders Mermaid to themed, sanitised SVG in the browser on save, uploads it directly to Storage under admin RLS, and the save action re-checks every diagram SVG on the server.

**Tech Stack:** Next.js 16 (App Router, Cache Components), React 19, TypeScript, Radix Dialog, Supabase (Postgres + Storage), Zod, next-intl, Vitest + Testing Library, Playwright + axe, mermaid 12.2.0 (admin only), dompurify 3.4.17.

**Spec:** `docs/superpowers/specs/2026-10-31-case-study-gallery-design.md`

## Global Constraints

- Home initial JS must not grow (199.8 KB of 200 KB gzip). Nothing new may be imported by home-page client code except through the existing lazy panel chunk.
- The 図 chunk and the viewer chunk are lazy and each ≤ 25 KB gzip; the bundle check enforces it.
- Panel fit rule: measured, never clipped; overflow sets `data-mode="scroll"` (CaseStudyPanel `measure`).
- Motion only under `:root[data-motion="full"]`; reduced motion uses opacity changes ≤ 150 ms.
- Font-subset budget tests scan all of `src` including comments: run `npm run test:budgets` after adding any non-ASCII text; no arrows or symbols in comments.
- At most 12 figures per project; caption ≤ 140, note ≤ 100 characters per locale; Mermaid source ≤ 20 000 characters; SVG ≤ 1 MB.
- Categories and kanji: `screen` 画, `architecture` 構, `erd` 表, `flow` 流, `other` 他.
- Storage paths: images `media/image/<unique>-<slug>.<ext>` (existing `storagePath`); diagrams `media/diagram/<project>-<figure>-<light|dark>-<hash8>.svg`.
- Diagram labels in English; captions, notes and alt in EN/JA/VI (JA/VI fall back to EN).
- Hosted DB: additive migration only; the owner runs it in the SQL Editor (ADR-0012). No agent DDL on the hosted project.
- Commits: conventional style, no "Co-Authored-By" or "Generated with" lines. Run `npm run verify` before every push. Never use port 3000 (Playwright uses 3100); never `taskkill /IM node.exe`; never `rm -rf`.
- Local e2e uses the seed: `NEXT_PUBLIC_SUPABASE_URL= NEXT_PUBLIC_SUPABASE_ANON_KEY=`.

## Review Focus

1. A project with figures but the visitor on a narrow or short screen (scroll mode): the 図 view must not clip the caption or the filmstrip, and the stage must keep 16:10 with a horizontally scrolling filmstrip. Pinned by Task 3 e2e "figures in scroll mode keep caption and strip visible at 375x740".
2. `?case=<id>&fig=<n>` with n out of range, non-numeric, or the project having no figures: opens figure 1, or 文 when there are none, never throws. Pinned by Task 3 unit `parseFigParam` cases.
3. An admin save where one of several diagrams fails to render (syntax error) or upload fails: nothing is written, the message names the figure, and figures rendered before the failure are not left referenced. Pinned by Task 6 unit "save stops and writes nothing when the second diagram fails".
4. A crafted SVG URL pointing outside our bucket, or an SVG with `<script>`, `on*` attributes, `javascript:` or external `href`, submitted straight to the save action: rejected server-side. Pinned by Task 5 unit `isSafeSvg` and Task 6 unit "saveResource rejects an unsafe diagram".
5. Rapid ←/→ presses and Esc during the open/close transitions: no queued animations, focus lands on the stage after the viewer closes, no stuck `inert`. Pinned by Task 3 unit "rapid presses cancel the running figure transition" and Task 4 e2e "Esc during open returns focus to the stage".
